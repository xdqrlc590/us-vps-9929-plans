## 9929 到底优化了哪几段

第三方测评（2026 年 9 月，测试环境为移动网络）给出的路由是这样的：

- 去程：电信走 163 骨干网，联通走 AS9929，移动走 CMI 骨干网。
- 回程：电信和联通走 AS9929，移动走 CMI。

要说清楚的是，这不是三网全程 9929。电信用户去程仍是普通 163 骨干，优化集中在回程；联通用户去程和回程都走 9929。回程决定从服务器往下拉数据的速度和晚高峰稳定性，对建站、下载、远程桌面这类读取为主的场景影响更直接，所以电信去程没走 9929，回程的 9929 依然有用。
